Preserve the React/Vite application, German/English content, localStorage and JSON workflow.
Read docs/UI-SOURCES.md and src/theme.css before changing the interface.
Use the installed Impeccable skill for scoped design refinement and review.
For new components, search the Watermelon MCP and retrieve the actual source before adapting it. When 21st MCP has a valid API key, use its search/get_component tools for comparison. Do not claim retrieval or installation when the connection is unavailable. Preserve licenses and record the upstream source and revision in docs/UI-SOURCES.md.
Prefer reusable components in src/components, semantic color tokens, keyboard controls and readable content. Honor prefers-reduced-motion. Lenis is managed by App; do not add a second scroll instance or smooth scroll inside editors, code panels or dialogs. Check both themes, both languages and narrow screens.
